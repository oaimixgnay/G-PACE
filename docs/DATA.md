# Input data

Place the original data outside the repository and provide its absolute directory to the workflow. Local copies under `data/raw/` are ignored by Git.

## European maize data

Use the original European maize multi-environment data release used in the experiments, including the supplied genotype/environment partition files.

Required filenames:

```text
1-Env_variables_daily.csv
2b-GrainYield_components_BLUEs_level-1.csv
3-Indices_GenoEnv_level-1.csv
7a-Genotyping_50K_41722.csv
7c-Genotyping_50K_41722_nG.csv
9a-CrossValidation_Sets_Geno.csv
9b-CrossValidation_Sets_Exp.csv
```

Validate inputs with:

```bash
python scripts/validate_data.py --data-dir /absolute/path/to/european_data
```

The internal panel comprises 246 genotypes, 25 environments and 6,150 records. External sets contain 383 and 224 records. The saved Day-100 parameters are in `configs/europe_day100.json`.

## G2F

Required filenames:

```text
1_Training_Trait_Data_2014_2023.csv
2_Training_Meta_Data_2014_2023.csv
4_Training_Weather_Data_2014_2023_full_year.csv
5_Genotype_Data_All_2014_2025_Hybrids_numerical.txt
1_Submission_Template_2024.csv
2_Testing_Meta_Data_2024.csv
4_Testing_Weather_Data_2024_full_year.csv
7_Testing_Observed_Values.csv
```

Models are trained on permitted 2014–2023 historical records and evaluated on 9,486 records from 22 environments in 2024. Test yields are evaluation labels. The TCN–FiLM architecture and yield parameters are retained in `experiments/g2f_tcn_film/config/`.

## Included numeric references

- `data/source_data/g2f_combined_predictions.csv.gz`: current six-model predictions; 170,748 rows.
- `data/frozen_comparators/g2f_predictions.csv.gz`: original prediction archive used to retain the five comparator models when replacing G-PACE predictions.
- `data/reference_runs/`: CPU paired-control predictions and completed-run records.
- `data/reference_summaries/g2f_controls/`: scalar reference values used by paired recalculation checks.
- `data/source_data/phenology_shuffle_null.csv` and `phenology_shuffle_summary.csv`: 6,000 within-environment exposure-permutation coefficients and six summaries. Legacy filenames are retained for compatibility.

Large model weights and cross-fit NPZ caches are generated by training and stay under the selected output directory.
